# קלפי נגישה

אתר עברי נגיש לאיתור קלפיות נגישות מיוחדות ולבדיקת מידע על נגישות קלפי.

## שימוש באתר

לאחר הפרסום ב־GitHub Pages, האתר יהיה זמין בכתובת:

<https://aviadn-byte.github.io/kalpi-negisha/>

## מקור הנתונים

האתר מבוסס על הקבצים „דוח 104 קלפיות למוגבלי ניידות לשנת פנקס” ו„דוח 137 סטטיסטי טופס ב׳ סופי”. המקור הרשמי: [דף „מידע לבוחר” של ועדת הבחירות המרכזית באתר gov.il](https://www.gov.il/he/pages/26elections-info?chapterIndex=2).

האתר אינו שירות רשמי. מיקומי קלפיות והסדרי נגישות עשויים להשתנות, ולכן יש לאמת את המידע בפרסום הרשמי סמוך למועד הבחירות.

## הפעלה מקומית

זהו אתר סטטי. אפשר להגיש את תיקיית `dist` באמצעות כל שרת קבצים סטטי.
